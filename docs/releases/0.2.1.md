# pyspharm-ng 0.2.1

Released: 2026-08-19

## Summary

`pyspharm-ng` 0.2.1 is a patch release focused on real Fortran-core
modernization. It preserves the public `pyspharm` API, the historical `spharm`
compatibility API, the F2PY symbols used by downstream callers, and the
single-precision SPHEREPACK numerical boundary.

This release replaces a set of small compiled F77 adapters with maintained
free-form Fortran modules while retaining the original F77 files as provenance.
The larger SPHEREPACK transform and Gaussian-quadrature kernels remain on the
legacy fixed-to-free conversion path.

## Highlights

- Modern free-form Fortran implementations for low-level spectral operators:
  `lap`, `invlap` and `multsmoothfact`.
- Modern free-form Fortran adapters for pointwise interpolation:
  `getlegfunc` and `specintrp`.
- Modern compact/expanded scalar spectral-storage adapters:
  `onedtotwod` and `twodtooned`.
- Modern compact/expanded vector spectral-storage adapters:
  `onedtotwod_vrtdiv` and `twodtooned_vrtdiv`.
- Explicit normalization of the non-representable total-degree-zero vector mode
  for vorticity/divergence storage.
- Modern free-form Fortran implementation of the geodesic coordinate generator
  `ihgeod`.
- Stage 8 modernization documentation and direct analytical/geometric
  regression coverage.

## Compatibility

No public Python API additions, removals or renames are introduced in this
release. Existing `pyspharm` and `spharm` imports remain supported.

The release keeps the established ABI and numerical boundary:

- transform grids remain `float32`;
- compact spectral coefficients remain `complex64`;
- F2PY wrapper names and argument order are preserved;
- `legacy-contract-v1` remains unchanged.
