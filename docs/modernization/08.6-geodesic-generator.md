# Stage 8.6 — Geodesic coordinate generator

This increment replaces the compiled `ihgeod` helper with maintained free-form
Fortran in `src/modern/spharm_geodesic.f90`.

The external F2PY symbol, argument order and output arrays are unchanged. The
modern code keeps the unfolded-icosahedron construction used by the historical
routine, but separates spherical/cartesian conversion, interpolation over the
faces and final unit-sphere normalization into explicit helper procedures.

The historical `src/ihgeod.f` file remains in the source tree as provenance
only. Meson and the fixed-to-free conversion manifest no longer compile or
convert it.

The public Python helper `pyspharm.geodesic_points` is unchanged. Tests verify
unit-sphere cartesian coordinates, fivefold longitudinal symmetry, the twelve
vertices of the edge-two icosahedron and the edge-one pole-only case.

The Gaussian quadrature routine and the scalar/vector transform kernels remain
on the legacy conversion path because their numerical algorithms need larger,
separate acceptance tests.
